# plane_cut_block API

`plane_cut_block(mesh, pa, pb, pc_n, pd, heap, scratch_heap, kernel_error) -> PartPair` -- device function, one block (64 threads).

- **Input**: `const Mesh*` (replaces separate verts/tris/nv/nt params).
- **Output**: returns a `PartPair` directly (stored in `__shared__ PartPair s_result`); `pos.mesh` and `neg.mesh` each have their own independent heap allocation from `DeviceHeap* heap`.
- **Heap chunk layout** (two `heap_alloc` calls on `heap`): pos chunk `[verts | tris | refcount(16B)]`, neg chunk `[verts | tris | refcount(16B)]`, each section 16-byte aligned. `pos.mesh.refcount` and `neg.mesh.refcount` point to independent `int`s in their respective chunks; each initialized to 1. `pos.mesh.verts` and `neg.mesh.verts` are both the starts of their respective allocations -- `heap_free(mesh.verts)` is always valid. Early-exit (no-cross) case allocates one chunk `[verts | tris | refcount(16B)]` for the non-empty side. Input meshes not allocated via `plane_cut_block` have `refcount = NULL`.
- **Scratch**: all temporary buffers (signs, all_verts, cross_edges, sort_scratch, isect_idx, pos_tris, neg_tris, cap_tris, dir_edges, dir_sort, boundary_flags, and per-loop working buffers) are allocated from `DeviceHeap* scratch_heap` and freed individually as soon as each buffer's last use completes. Nothing from scratch_heap survives the call. Scratch allocations are deferred where possible: `sort_scratch` and `isect_idx` are allocated after phase 3 when `n_cross` is known; `all_verts` is allocated after phase 4 once `sort_scratch` is freed, sized to `(n_verts + n_cross) * 3` (tighter than the `n_verts + n_tris*2` upper bound); original vertices are then copied into it in parallel (phase 4b, 64 threads) before the intersection loop. `dir_edges`/`dir_sort`/`boundary_flags` are allocated after phase 6 when actual triangle counts are known, and `cap_tris` is allocated after phase 9b when `n_boundary` is known (sized from actual boundary count, not theoretical max). `pos_tris`/`neg_tris` hold only phase-6 split triangles (`max_out_tris`); cap triangles are kept in `cap_tris` and merged into the output during phase 13 with winding adjustment and vertex remapping. Small-value buffers use minimal types: `signs` is `signed char` (-1/0/1), `boundary_flags` is `char` (0/1).
- **Boundary edge tracing (phases 7-9)**: traces the smaller of `n_pos`/`n_neg` triangle sides to find boundary edges -- halves average work and scratch allocation. `dir_edges`, `dir_sort`, and `boundary_flags` are sized from the actual traced count (`n_trace * 3`), not the theoretical maximum. Loop winding is normalized by signed-area orientation in phase 11, so tracing either side produces identical boundary topology. Phase 8 sorts `dir_edges` by the **normalized** (unordered) key `(min(a,b), max(a,b))` using `Edge2iNormCmp`, so that each internal edge's two directed forms `(a,b)` and `(b,a)` are adjacent in sorted order. Phase 8 uses a **two-warp parallel quicksort**: for arrays > 32 elements, warp 0 performs one pivot+partition pass (via `warp_pick_pivot` + `warp_partition`) splitting `dir_edges` into left and right halves, then warp 0 and warp 1 simultaneously sort the left and right halves respectively using `warp_sort_inner` with independent stack arrays. The shared `tmp` buffer is safe to share because the two halves occupy disjoint index ranges. `dir_sort` scratch is sized with 4 stack arrays (`WS_MAX_STACK * 4 * sizeof(int)`) instead of 2. Phase 9 detects boundary edges via a simple **neighbor scan** (O(1) per thread): an edge is a boundary edge iff neither its left nor right sorted neighbor has the same normalized key. This replaces the former O(log n) binary search for the reverse edge. Directed values `(a,b)` are preserved in `dir_edges` for phases 9b-10.
- **Boundary edge compaction** (phase 9b, parallel): after phase 9 flags boundary edges, all 64 threads compact flagged edges into a packed array using `atomicAdd` on `__shared__ s_n_boundary`. This replaces the former serial thread-0 loop.
- **Warp-cooperative phases 10-12**: loop reconstruction, hole classification (ray-cast PIP), and ear-clip triangulation run on warp 0 (32 lanes). Lane 0 handles heap alloc/free and serial control flow; all 32 lanes cooperate on inner scans (boundary edge chain search via `__ballot_sync`/`__shfl_sync`, ray-cast crossing count via warp-reduce, ear-clip point-in-triangle via parallel index scan with `__ballot_sync`). **Parent-tree cycle detection**: after building the parent chain via point-in-polygon containment tests, the code walks each chain (lane 0 only) and checks for cycles (chain length > n_loops). If a cycle is found (ambiguous containment from near-shared vertices), the cap is treated as failed (`s_n_cap = -1`) and the mesh is returned unsplit — skipping depth classification, hole reversal, and ear-clipping entirely. The `parent` and `is_hole` arrays are proper `CheckedBuf<int>` with bounds 128, not raw pointers.
- **Vertex compaction** (phase 13, parallel): phases 1-9 run on thread 0 or warp 0; phases 10-12 run on warp 0 (32 lanes); phase 13 runs across all 64 threads. Steps: init remap[]=-1 (strided), mark used verts via `atomicMax` (strided), count per contiguous chunk, exclusive prefix scan (thread 0, 64 iters), assign new indices per chunk, remap tris in-place (strided), heap alloc (thread 0), scatter verts + copy tris (strided). Each side's `Mesh.verts` contains only the vertices actually referenced -- no loose vertices.
- **Counters** (`n_cross`, `n_all_verts`, `n_pos`, `n_neg`): stored in `__shared__ int s_counters[4]`; `atomicAdd` on shared memory. Not on heap.
- **Early exit** (`n_cross == 0`): if all vertices are on one side, entire input mesh goes to that side; other side gets empty `Mesh {NULL,NULL,0,0}`. If vertices exist on both sides (disjoint components separated by the plane), triangles are classified by vertex sign, vertices are compacted per side, and two separate meshes are output — no cap triangulation needed since no edges cross the plane.
- **No-boundary / one-empty-side cases**: handled by natural fallthrough -- compaction produces a 0-entry side correctly.
- **Call sites**: `test_plane_cut.cu` (thin `__global__` wrapper) and `test.c` (host launcher) pass `DeviceHeap*` pointers into the embedded heaps of `DevicePool`.
